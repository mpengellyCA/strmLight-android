The first StrmLight: watch StrmQt on a Fire TV or Android TV and drive it with the TV's own remote. Open it, type one code into StrmQt, and you're watching.

StrmLight needs **StrmQt 0.9.0 or newer** with its streaming host set up (StrmQt: Settings › Web Remote › Streaming host).

## Install

StrmLight is not in the Amazon or Google stores yet; install the APK by hand.

| File | What it is |
|---|---|
| `StrmLight-0.9.0.apk` | The app, for every Fire TV and Android TV (Android 5.0 or newer) |
| `StrmLight-0.9.0.apk.sha256` | Its SHA-256, to check the download |

- **Fire TV:** install the *Downloader* app from the Amazon store, allow it to install unknown apps (Settings › My Fire TV › Developer options › Install unknown apps), and open this release's APK link in it.
- **From a computer:** turn on ADB debugging on the TV, then `adb connect <tv-address>` and `adb install StrmLight-0.9.0.apk`.

It installs beside Moonlight, if you have it, and does not touch Moonlight's settings or pairings.

## Setting it up

1. On the computer, set up StrmQt's streaming host once (Settings › Web Remote › Streaming host).
2. Open StrmLight. It finds StrmQt on your network by itself and shows a four-digit code.
3. Type the code into StrmQt, under Settings › Web Remote › **Pair a StrmLight**, or on StrmQt's phone remote under **Pair a StrmLight**. That one code pairs the picture and the remote.
4. StrmLight says Connected and starts the stream. From then on, opening it goes straight to StrmQt.

Addresses, ports and Moonlight's own settings are under **Advanced setup**, for when the host is not found by itself.

## What's in it

- **Finds StrmQt by itself** on the local network, with a chooser when there is more than one.
- **One code** pairs both the Moonlight stream and StrmQt's remote.
- **The TV's remote drives StrmQt directly**: arrows, OK, Back, play and pause go to StrmQt rather than as keys through the stream. Hold Back for two seconds in the stream for StrmLight's menu (Return to StrmQt, Disconnect, Settings).
- **Reconnects by itself** when the stream drops, and connects on launch.
- **StrmQt's look**: the same warm black, amber and type as StrmQt, and focus you can see from the couch.

## Known limitations

- **One day old.** It has run on one Fire TV (Fire OS 7, Android 9) against one StrmQt host.
- **Not in any store**, so it does not update itself. Install the next release's APK over this one; it keeps your pairing.
- **The host's name is the computer's name** (for example `my-pc`); StrmQt has no setting for a friendlier one yet.
